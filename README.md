# Ứng dụng mẫu cho các khóa học Claude Code của CodeGym

Kho này chứa các ứng dụng mẫu dùng trong lộ trình **Lập trình với Claude Code** trên CodeGym Learn. Mỗi ứng dụng nằm trong một thư mục riêng, có README hướng dẫn cài đặt và chạy.

| Thư mục | Khóa học | Mô tả |
|---|---|---|
| `so-thu-chi-clb/` | Lập trình với Claude Code | Sổ thu chi câu lạc bộ: ứng dụng web nhỏ (Python, FastAPI, SQLite, pytest) quản lý thành viên, khoản thu, khoản chi và báo cáo của câu lạc bộ sinh viên. |

## Cách dùng

1. Bấm **Fork** để tạo bản của riêng bạn.
2. Clone bản fork về máy, rồi mở thư mục của ứng dụng mà khóa học yêu cầu.
3. Làm theo README trong thư mục đó và hướng dẫn trên CodeGym Learn.

Ứng dụng mẫu có những lỗi và những chỗ chưa tốt được cài sẵn có chủ đích để phục vụ bài học. Đừng báo lỗi cho kho này; hãy sửa chúng trong bản fork của bạn theo hướng dẫn của khóa học.
